## 详细版

### 出问题时有据可查了（1.3.11）

以前闪退只能描述「它突然没了」，这次起运行日志和崩溃堆栈都会写进应用私有目录：

- **运行日志**：自动轮转，最多占约 1.5 MB，不会越攒越大
- **崩溃记录**：闪退时把堆栈、机型、系统版本、出错线程存下来，保留最近 5 份
- **导出**：设置 → 诊断与日志 → 「选择位置导出…」，内部存储 / SD 卡 / 网盘都行，
  文件名可当场改。导出的是纯文本，手机上直接能看
- 可以随时关掉记录，也可以一键清空（会二次确认）

顺手补掉几处会直接闪退的地方：找不到系统权限设置页时点「去授权」、索引文件被换掉后
搜索航图、网页回调里出现意料之外的内容。

### 导入数据（1.3.7 / 1.3.12）

- **选文件夹**：导航包解压后指到那一层就行，程序自己挑
  `earth_fix` / `earth_awy` / `earth_nav` / `earth_aptmeta`，用不上的自动忽略
- **压缩包直接选**：不用先解压，程序边解压边送
- **修**：选 zip 导入时报「数据未生效：数据不可用」
- **修**：导入失败会把正在用的数据一起弄丢
- **修**：导入 AIP 航路表后，起降机场被清空、算不了航路
- 压缩包里缺哪个文件会直接说清楚，不再是笼统的「导入失败」

### 航路 / 油量（1.3.8 / 1.3.9 / 1.3.11）

- **航路生成器升到 v8.6**：白天 / 黑夜模式、手机竖屏适配、机场数据更全
  （可选机场 16698 → 23157）、终端区不再被巡航高度卡死
- **修**：航路规划出来的航程填不进油量计算器
- **修**：切到油量计算器再切回来，已经生成的航路消失
- 生成的结果会一直留着，直到你自己点页面上的「清空」

### 检查单（1.3.11 / 1.3.12）

- **自定义检查单放在最上面**，不再混在「其他」分类里
- **空客 / 波音 / 其他都能收起**，标题后面带机型数量
- **可以分享**：自定义检查单 → 导出成 JSON，别人导入就能用。
  导入的是一份独立副本，不会和你原有的共用勾选进度
- 勾选项的上下间距加大到 48dp 触控高度，颠簸或戴手套时更好点

### 设置页（1.3.10）

改成分组卡片：航图库 / 数据与索引 / 显示与交互 / 规范与维护 / 诊断与日志，
路径不再被裁、可一键复制，换航图库目录不用再重跑整套引导。

### 界面（1.3.12）

系统栏留白之前算了两遍，导致标题离刘海远出一条状态栏、列表底边也悬在底栏上方。
这次收掉了，内容更贴边。
