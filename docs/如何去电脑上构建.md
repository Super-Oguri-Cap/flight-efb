## 2. 环境变量

每一步构建前在当前 PowerShell 会话里设置（不写进系统环境，避免影响其它项目）：

```powershell
$env:JAVA_HOME='E:\_Code ide\JAVA\jdk-17'
$env:ANDROID_HOME='E:\Android\sdk'
$env:ANDROID_SDK_ROOT='E:\Android\sdk'
# 不要设 GRADLE_USER_HOME：留空才会用默认的 C:\Users\<用户>\.gradle（依赖已铺好）。
# 之前写死指到 E:\Android\gradle-home，那份缓存从未被构建使用过，已于 2026-11-09 删除。
```

## 3.1 测试跑多了会撑爆 C 盘（2026-11-09 补）

Robolectric 每次跑 `testDebugUnitTest` 都会把约 201 MB 的 Android 原生运行时解压到
`%TEMP%\robolectric-nativeruntime<随机数>`，正常退出会自动删，但构建被中断（Ctrl+C、
杀 daemon、超时）时就会残留。本机一度堆了 8 份、1.41 GB。

定期清理（只删这一个前缀，别的临时文件不动）：

```powershell
Remove-Item "$env:TEMP\robolectric-nativeruntime*" -Recurse -Force -ErrorAction SilentlyContinue
```

副作用只有一个：下次跑测试要重新解压一份（多花几秒）。

## 4. 装 SDK 时踩到的坑

**`sdkmanager` 不可用。** 新版 cmdline-tools 里的 `sdkmanager.bat` 是 `android.exe` 的转发壳，运行时要把内嵌 JDK 解压到 `C:\Users\<用户>\.android\cli\bundles\`，本机在这一步报 `i/o error: 拒绝访问 (os error 5)`。

绕开的办法：直接从 `https://dl.google.com/android/repository/` 下载三个 zip 手工解压——

| 文件 | 解压到 |
|---|---|
| `platform-36_r02.zip`（63 MB） | `<sdk>\platforms\android-36` |
| `build-tools_r36_windows.zip`（56 MB） | `<sdk>\build-tools\36.0.0` |
| `platform-tools_r37.0.2-win.zip`（8 MB） | `<sdk>\platform-tools` |

再手写 license 文件，否则 Gradle 会拒绝构建：

```powershell
$lic = 'E:\Android\sdk\licenses'
New-Item -ItemType Directory -Path $lic -Force | Out-Null
$sha = '24333f8a63b6825ea9c5514f83c2829b004d1fee'
foreach ($k in 'android-sdk-license','android-sdk-preview-license','android-sdk-arm-dbt-license') {
    Set-Content -LiteralPath (Join-Path $lic $k) -Value $sha -NoNewline
}
```

**Gradle 发行包下载源不通。** `services.gradle.org` 与 `downloads.gradle.org` 在这个网络下连不上。wrapper 的 `distributionUrl` 已经指向腾讯云镜像：

```
distributionUrl=https\://mirrors.cloud.tencent.com/gradle/gradle-8.14.3-bin.zip
```

**工程路径含中文。** AGP 会因为 `E:\...\飞行EFB` 抛「Your project path contains non-ASCII characters」。`gradle.properties` 里已经加了：

```
android.overridePathCheck=true
```

光加这一条只能让构建过；测试仍会因为 classpath 里的中文被 URL 编码而 `ClassNotFoundException`。真正的解法是把编译产物输出到纯 ASCII 路径，`app/build.gradle.kts` 里已经这么做：

```kotlin
android {
    layout.buildDirectory.set(file("E:/Android/efb-build/app"))
}
```

## 5. 装 APK 到手机

```powershell
& 'E:\Android\sdk\platform-tools\adb.exe' install -r "E:\Android\efb-build\app\outputs\apk\release\app-release.apk"
```

首次运行要授权「所有文件访问权限」（系统会跳到设置页），然后在文件选择器里选中手机上的 `/sdcard/飞行/AIP航图库`。

## 6. 签名

`keystore\efb-release.jks`，别名 `efb`，RSA 4096 位，有效期 30 年。debug 与 release 都用它签名，换机器后覆盖安装不会因签名不一致失败。

证书文件已加入 `.gitignore`，单独备份一份到工程外。
