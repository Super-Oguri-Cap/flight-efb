# 飞行EFB v1.3.6 发行说明

离线电子飞行包：查 AIP 航图、跑检查单、翻 QRH 手册，现在还能**在机上算航路与油量**。**全程不联网**，航图与手册只读，任何操作都不改动原始文件。

> **仅供飞行模拟使用（for simulation only），不得用于真实飞行。**

## 二、安装

### 手机直接装

1. 把 `flight-efb-1.3.6.apk` 传到手机（数据线、蓝牙、微信文件传输均可）
2. 用文件管理器打开安装；系统提示「未知来源应用」时允许本次安装
3. 首次启动按引导走四步：**欢迎 → 授权「所有文件访问权限」→ 选航图库目录并扫描 → 确认结果**

### 用 adb 装

```bash
adb install -r flight-efb-1.3.6.apk
```

> ✅ 签名证书与 1.2.2 **相同**（指纹 `2ac5abec…`），已装 1.2.2 的可以直接覆盖安装，勾选进度与已选航图都保留。
>
> ⚠️ 更早的 1.1.0 及之前版本证书不同，需要先卸载。

## 三、本版（1.3.6）更新

### 修复

| 问题 | 原因与处理 |
|---|---|
| **航路页「导入数据」点了没反应** | 两层原因：① 面板里那句「把导航数据拖到这里，或点击选择文件」其实是一个隐藏的 `<input type=file>`，WebView 没有实现文件选择回调，点它什么都不会发生；② 1.3.2 接上回调后仍不弹，因为桥方法与被调回调同名，Kotlin 把它解析成了递归调用，主线程被无限空转占满。1.3.3 已两处都修好：由 App 弹系统文件选择器，选完走分块注入管线，成功后数据面板自动收起 |

### 调整

| 项 | 说明 |
|---|---|
| **底部标签改名「航路/油量」** | 原「工具」，功能不变 |
| **油量页机型 / 规章选择弹层重做** | 原来是原生下拉，在 WebView 里弹系统菜单，和页面深色主题完全脱节。现在换成自绘底部弹层：深色玻璃卡片 + 主色描边；机型按制造商分组、选中项高亮打勾并自动滚进视野；点遮罩或「关闭」收起。**计算逻辑一行没改**，`<select>` 仍是唯一数据源，选中后照常触发重算 |
| **航路页顶栏窄屏适配（本版）** | 原来固定 50px 单行，手机上品牌行被折成三行后裁掉、数据标签撑宽整行。现在窄屏可换行、按内容撑高；宽屏不变 |
| **AIP 表 / 数据包导入接通（本版）** | 三个入口统一走系统选择器，按类型分流到页面自己的解析器；导出 → 再导入的闭环可用 |
| **油量计算器升级 V7（1.3.4）** | 新版新增日间 / 夜间模式，右上角可切换。页面文件整体替换，弹层配色也跟着 `html[data-theme="light"]` 走。**这次升级 Kotlin 一行没改、补丁配置一行没改**，只换了 HTML |
| **1.3.1 的触摸修复** | 1.3.0 的两个 WebView 会互相抢触摸（航路页点不动），1.3.1 起改为同一时刻只挂载一个 |

> 1.3.0 引入的工具页与自定义检查单能力见下一节「功能概览」，本版未改动它们。

### 兼容性

- 与 1.2.2 的检查单进度、已选航图、设置项**完全兼容**，覆盖安装不需要迁移
- 「航路/油量」相关数据存在独立 SharedPreferences（`efb_tool_routes` / `efb_tool_imports` / `efb_custom_checklists`），卸载即清空

## 四、功能概览

### 航图

预置索引 **3203 张 / 84 个机场**，按图型分类（ADC / GMC / APDC / SID / STAR / IAC / AOC / ATCSMAC / CODING / ENR / OTHER）。

- 搜索：四字码、机场名、图名（中文匹配置顶）
- 选中：机场页右上角进选择模式，多选后「加入离场 / 加入进场」，置顶显示
- 阅读：双指缩放 1–6 倍、双击放大、放大后单指推图、反色、预渲染下一页

### 检查单

- 22 个机型 / 2314 条内置数据（simchecklists，MIT）
- 逐条勾选、每阶段独立重置、分组互斥
- **自定义检查单**：复制内置机型 → 编辑器里改名/增删/排序 → 即时保存；勾选按条目 uid 记录，重排不串位

### QRH

- 内置 3 个分组 / 16 条处置（自行整理，非空客或波音受控文件）
- 另附两份 PDF 原件，用同一套阅读器打开

### 工具（本版新增）

| 子页 | 能力 | 需要的数据 |
|---|---|---|
| 航路生成器 | 起降机场 + 巡航高度 → 官方/走廊推荐与引擎方案，显示距离、航段数、高度合规性；可复制、可保存 | `earth_fix.dat`、`earth_awy.dat`（必需）+ `earth_nav.dat`、`earth_aptmeta.dat`（建议） |
| 油量计算器 | CAAC / FAA / EASA 三种规则、机型参数、备降与等待油量、爬升油 | 无，开箱可用 |

> 导航数据请到 X-Plane 12 安装目录的 `Custom Data`（或 `Resources/default data`）里取。**本 App 不提供、不下载、不分发这些数据。**

## 六、航图库目录要求

应用靠目录名识别机场与图型：

```
AIP航图库/
├─ ZBAA_北京_首都/
│   ├─ 01_机场图ADC/
│   ├─ 04_离场图SID/
│   ├─ 05_进近图IAC/
│   └─ 06_进场图STAR/
└─ 00_ENR通用资料/
```

完整规则见仓库里的 `航图库结构与命名规范.md`；应用内「设置 → 生成规范文档」也会把它写到手机 Download 目录。

## 七、已知限制

| 级别 | 内容 |
|---|---|
| 🟡 | 工具页的网页数据只在内存里，切到别的标签再回来会**按上次选的文件重新解析一遍**（导航数据不落盘是刻意设计，避免把受限数据写到手机上） |
| 🟡 | 航路生成器需要 `earth_aptmeta.dat` 或 `apt.dat` 才有机场可选；只导 `earth_fix` + `earth_awy` 能算出航段但没有起降机场 |
| 🟡 | 777 与 757 检查单暂缺，公开来源没有这两份 |
| 🟡 | 内置 QRH 的 16 条为自编整理，使用前请按实际机型核对 |
| 🟢 | 自定义检查单、已存航路、勾选进度都存在应用私有目录，卸载即清空，不跨设备同步 |
| 🟢 | 网页工具来自项目自研的单文件 HTML，升级方式是「换文件 + 重新出包」，`ToolAssetsContractTest` 会在出包期拦截不兼容改动 |
