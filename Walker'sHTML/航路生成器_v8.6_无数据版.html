把导航数据拖到这里，或点击选择文件 最省事：直接拖整个 .zip（Navigraph / Aerosoft 的 X-Plane 包）。
里面的 fix / awy / nav / aptmeta 会自动识别，CIFP 与 atc/airspace 自动跳过。
必需earth_fix.dat所有航路点坐标
必需earth_awy.dat航段（哪两点之间有航路）
推荐earth_aptmeta.dat机场坐标与标高，导航包自带；有它就不需要 apt.dat
可选earth_nav.datVOR / NDB，补全航段端点
可选apt.datX-Plane 自带，机场更全（含小机场 / 直升机场）；没有就用 aptmeta
apt.dat 和 earth_aptmeta.dat 只导一个也行
· 只导 apt.dat → 机场最全（含直升机场、水上基地，这两类不会进可选列表）
· 只导 earth_aptmeta.dat → 约 2.3 万个 IFR 机场，够用
· 两个一起导 → 自动合并：apt.dat 优先，aptmeta 补齐它没有的机场（合计约 4 万个）
earth_hold / earth_mora / earth_msa、atc.dat、airspace.txt 会被读入但本工具用不到； CIFP 里上万个进离场文件直接跳过。
文件只在本机浏览器内解析，不上传
这三个文件在哪？
Steam 版：…\steamapps\common\X-Plane 12\　 独立安装：<X-Plane 12 安装目录>\
· Custom Data\earth_fix.dat
· Custom Data\earth_awy.dat
· Custom Data\earth_nav.dat
· Global Scenery\Global Airports\Earth nav data\apt.dat
没装 Navigraph / Aerosoft 订阅的话，同名的 fix / awy / nav 文件在 Resources\default data\ 下也有一份（游戏自带、周期较旧，一样能用）； apt.dat 只有上面那一个位置。
拖入 AIP 航路表：.csv / .json 支持 CAAC 四张表的 CSV（文件名含 from mainland / to mainland / overflying / regional），
也支持本工具导出的 caac_official.json。
CSV 要求：表头需含 Fly along（航路串）列；Route Code 取第一列， 形如 ZBAA-AGAVO-01；机场列表列名含 AD / destination 即可。
应用后会用它重新计算「国内走廊」与「航路优先级」，所以要先导入导航数据。
拖入本工具的数据包 .json 即 {NODES_GLOBAL, SEGMENTS_GLOBAL, AIRPORTS_GLOBAL}，与 lnm_pack.json 同格式。
导出的数据包就是本工具的中间格式（base36 压缩），可以拷到别的机器上再导入，省得重复解析。
注意：如果你导入的是 Navigraph / Jeppesen 数据，导出的文件同样受原数据授权约束，请勿公开分发。
